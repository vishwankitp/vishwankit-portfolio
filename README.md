# Vishwankit Pandhare — Portfolio

A dark, responsive personal portfolio for Vishwankit Pandhare, a first-year B.Tech CSE (Cybersecurity) student at VIT Vellore.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, then inspect it locally with `npm run preview`.

## Notes

- Profile details and public links are kept together at the top of `src/main.tsx`.
- The email intentionally remains a placeholder until one is supplied.
- Project labels distinguish completed work, prototypes, and in-progress work without adding unverified claims.
- The interactive particle network is a dependency-free Canvas implementation, and motion is reduced automatically for users who request reduced motion.
